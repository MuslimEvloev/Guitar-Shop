## 🧠 О проекте

**Guitar Shop** — учебный проект на чистом **HTML, CSS и JavaScript**.  
Сайт демонстрирует работу с интерактивными элементами, каталогом товаров и базовой логикой для интернет-магазина музыкальных инструментов.  

---

## 🧩 Используемые технологии
| Технология | Роль |
|-------------|------|
| 🧱 HTML5 | структура страниц |
| 🎨 CSS3 | оформление и стилизация |
| ⚙️ JavaScript | динамическое взаимодействие с пользователем |
